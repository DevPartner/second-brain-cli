# 🎯 Master Page in ASP.NET Web Forms - L1

## Question
>
> **Core Question:** What is a Master Page and how does it work in ASP.NET Web Forms?
> **Category:** Web Forms

## 💡 Quick Answer (30 seconds)

A Master Page defines shared layout (header, footer, navigation), while content
pages fill defined placeholders. It ensures consistent UI across pages.

## 📖 Detailed Explanation

- **Shared shell:** Put common structure once in the Master Page.
- **Content placeholders:** Child pages inject page-specific content.
- **Maintainability:** One layout update can affect many pages.
- **Typical use:** Branding, menus, common scripts/styles.
