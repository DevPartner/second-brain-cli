# 🎯 Stateless vs Stateful Protocols - L3

## Question

> **Core Question:** Explain the difference between stateless and stateful protocols? Which type of protocol is HTTP?
> **Follow-up:** How do web applications maintain state with a stateless protocol?

## 💡 Quick Answer (30 seconds)

- **Stateless**: Each request is independent, no memory of previous interactions
- **Stateful**: Server maintains connection state and remembers previous interactions
- **HTTP is Stateless**: Each HTTP request contains all necessary information
- **State Management**: Achieved through cookies, sessions, tokens, and URL parameters
