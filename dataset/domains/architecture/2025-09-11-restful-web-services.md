# 🎯 RESTful Web Services - L1

## Question
>
> **Core Question:** Describe RESTful Web Services and their advantages over SOAP-based web services.
> **Category:** MVC, HTTP

## 💡 Quick Answer (30 seconds)

RESTful services expose data through HTTP using standard verbs (GET, POST, PUT, DELETE) and can return data in multiple formats (JSON, XML). They're simpler, more performant, and more flexible than SOAP services, which expose methods exclusively using XML.
