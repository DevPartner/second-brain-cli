# 🎯 HTTP Status Codes Guide - L3

## Question
>
> **Core Question:** What is the difference between 200, 301, 400, 404, 500 status codes?
> **Follow-up:** When should you use each status code and what are the appropriate response patterns?

## 💡 Quick Answer (30 seconds)

- **200 OK**: Successful request, content returned
- **301 Moved Permanently**: Resource permanently moved to new URL
- **400 Bad Request**: Invalid request syntax or parameters
- **404 Not Found**: Requested resource doesn't exist
- **500 Internal Server Error**: Server encountered unexpected error

- **1xx (Informational)**: Request received, continuing process
- **2xx (Success)**: Request successfully received, understood, and accepted
- **3xx (Redirection)**: Further action needed to complete request
- **4xx (Client Error)**: Request contains bad syntax or cannot be fulfilled
- **5xx (Server Error)**: Server failed to fulfill valid request
