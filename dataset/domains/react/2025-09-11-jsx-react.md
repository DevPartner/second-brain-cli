# 🎯 JSX in React - L2

## Question
>
> **Core Question:** What is JSX in React? How does it work and what are its advantages over regular JavaScript?
> **Category:** JavaScript, React

## 💡 Quick Answer (30 seconds)

JSX is a syntax extension for JavaScript that allows writing HTML-like code in React components. It gets transpiled to React.createElement() calls, enabling declarative UI definition with type safety and component composition while maintaining the full power of JavaScript.

## 📖 Detailed Explanation

### What is JSX?

JSX (JavaScript XML) is a syntax extension that allows you to write HTML-like markup inside JavaScript. It makes React code more readable and expressive.
