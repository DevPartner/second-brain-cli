## Question

> **Core Question:** Should React code manually use CSS vendor-prefixed properties?
> **Follow-up:** What is the preferred modern approach for cross-browser CSS support?

## 💡 Quick Answer (30-60 seconds)

- Avoid manual vendor-prefixed style props unless absolutely necessary.
- Use PostCSS and Autoprefixer to generate prefixes automatically.
- Drive compatibility via browserslist instead of hardcoded hacks.
- `WebkitTransform` and `msTransform`

## 📖 Detailed Explanation

Historically CSS needed vendor prefixes for experimental features. In modern workflows, autoprefixing tools handle this at build time based on target browser versions. This keeps React components cleaner and easier to maintain. React still supports vendor-prefixed inline style keys when needed:

- `WebkitTransform` for older WebKit-based browsers (legacy Safari/Android WebView behavior).
- `msTransform` for legacy Internet Explorer (`ms` is the only lowercase vendor prefix in React style keys).

Practical rule:

- If your `browserslist` excludes legacy browsers, do not write manual vendor-prefixed inline props.
- If you must support old engines, add prefixed keys deliberately and document why.

### Before/After Example 1: React inline styles (manual legacy support)

```jsx
// Before: no legacy fallback keys
<div style={{ transform: "rotate(90deg)" }} />
```

```jsx
// After: explicit legacy compatibility for old WebKit/IE targets
<div
  style={{
    transform: "rotate(90deg)",
    WebkitTransform: "rotate(90deg)",
    msTransform: "rotate(90deg)",
  }}
/>
```

### Before/After Example 2: preferred modern workflow (Autoprefixer)

```css
/* Before (author-written source CSS) */
.card {
  user-select: none;
  appearance: none;
  transform: rotate(90deg);
}
```

```css
/* After (generated by Autoprefixer for older targets) */
.card {
  -webkit-user-select: none;
  -ms-user-select: none;
  user-select: none;
  -webkit-appearance: none;
  appearance: none;
  -webkit-transform: rotate(90deg);
  -ms-transform: rotate(90deg);
  transform: rotate(90deg);
}
```

```jsx
<button className="cta-button">Buy now</button>

/* CSS processed by Autoprefixer */
.cta-button {
  user-select: none;
  appearance: none;
}
```
