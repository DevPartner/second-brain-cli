## Question

> **Core Question:** Why are react and react-dom separate packages?
> **Follow-up:** How does this separation support multiple renderers like React Native?

## 💡 Quick Answer (30-60 seconds)

- react holds platform-agnostic core APIs and mental model.
- react-dom is the web-specific renderer for browser DOM.
- Separation enables other renderers such as React Native to reuse React core.

## 📖 Detailed Explanation

React was designed with renderer abstraction, where core logic is independent from rendering target. The web renderer is react-dom, while native rendering uses other renderer packages. This modular design improves portability and ecosystem extensibility. In interviews, connect this separation to architecture clarity and multi-platform support.

```jsx
import { createRoot } from "react-dom/client";

// Web renderer usage
createRoot(document.getElementById("root")).render(<App />);

// Native apps use a different renderer package (react-native)
```
