## Question

> **Core Question:** Is Next.js an alternative to Express, Hapi, or Koa, and what is it used for?
> **Follow-up:** When would you still use a custom backend framework with Next.js?

## 💡 Quick Answer (30-60 seconds)

- Next.js is a React framework for routing, SSR and SSG, and full-stack web app workflows.
- It can host backend logic, but it is not a universal replacement for all backend architectures.
- Use dedicated backend frameworks for complex services, protocols, or independent scaling.

## 📖 Detailed Explanation

Next.js optimizes React application delivery with built-in rendering strategies, routing, bundling, and deployment conventions. Its backend features can replace a separate server for many product scenarios. However, larger systems often keep dedicated backend services for domain logic, advanced middleware, websockets, or non-HTTP workloads. Interview framing should be complement or consolidate, not strict replacement.
