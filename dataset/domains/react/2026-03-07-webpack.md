# What is Webpack, when is it used, and what does it do in frontend builds? - L2

## Question

> **Core Question:** What is Webpack, when is it used, and what does it do in frontend builds?
> **Follow-up:** Does Webpack minify JS and CSS and compile Sass, and how does this differ in Next.js?

## 💡 Quick Answer (30-60 seconds)

- Webpack is a module bundler that produces optimized browser assets.
- With loaders and plugins it can transpile code, process Sass or CSS, and minify output.
- Next.js abstracts most bundler setup, but the same build concepts still apply.

## 📖 Detailed Explanation

Webpack builds a dependency graph from entry points and emits bundles optimized for delivery. It supports code splitting, tree shaking, and many transformations via loaders and plugins. Yes, it can minify JavaScript and CSS and convert Sass to CSS when configured. Next.js hides most configuration so developers can focus on product code, while still relying on bundling under the hood.

```jsx
// webpack module rule example
module.exports = {
  module: {
    rules: [
      { test: /\.scss$/, use: ["style-loader", "css-loader", "sass-loader"] }
    ]
  }
};
```
