# sitecore-blocks

## Source

From: GitHub Copilot

## Summary

Sitecore Blocks (Blok) is Sitecore's product design system and UI framework used to build visually consistent SitecoreAI and Marketplace experiences.

## Key insights

- Definition:
    In Sitecore Marketplace terminology, Blok is the Sitecore product design system and style guide for building SitecoreAI user interfaces.
    Source: <https://doc.sitecore.com/mp/en/developers/marketplace/marketplace-glossary.html#marketplace-glossary>

- Official references:
    The canonical references are the Blok website and GitHub repo.
    Sources:
    <https://blok.sitecore.com>
    <https://github.com/Sitecore/blok>
    <https://doc.sitecore.com/mp/en/developers/marketplace/blok-design-system-reference.html#blok-design-system-reference>

- Why it matters in Marketplace apps:
    Sitecore recommends aligning app design with Blok so custom/public apps match Sitecore look and feel and deliver consistent UX.
    Source: <https://doc.sitecore.com/mp/en/developers/marketplace/introduction-to-sitecore-marketplace-for-custom-and-public-apps.html#workflow-for-creating-apps>
